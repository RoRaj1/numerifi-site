# Numerifi site

Static marketing site: plain HTML pages (`index.html`, `about.html`, `careers.html`, `courses.html`, `donate.html`, `forum.html`, `workshops.html`), shared `styles.css`, and `script.js`. The logo is `logo.png`, referenced via `.brand-mark` in the nav and footer of every page.

## Workflow

Whenever the user tells you to make a change, after making it: `git add`, `git commit`, and `git push` the change without asking for confirmation first.
